# CV-Customizer
CV Customizer — A Chrome extension that uses AI (via OpenRouter) to generate tailored professional summaries for your resume. Open any job posting, and it automatically crafts a customized summary based on the job description, your existing CV, and base summary — then exports an updated .docx file ready to download.
📄 How to Use CV Customizer
1. ⚡ Prerequisites & Template Setup
OpenRouter API Key: Get a key from openrouter.ai.
Resume Template: In your .docx resume file, place the exact placeholder text [CV Customize] where you want your professional summary to go.
2. 📥 Install in Chrome
Open Chrome and go to chrome://extensions/.
Turn on Developer mode (top-right toggle).
Click Load unpacked (top-left button).
Select your CV Customizer project folder.
3. 🚀 Quick Usage Guide
Configure Settings (First time only):

Click the CV Customizer extension icon in your Chrome toolbar.
Enter your OpenRouter API Key.
Pick an AI Model (or select Other (custom model) and type a model ID like google/gemini-2.5-flash).
Enter your Base Professional Summary.
Upload your .docx resume file (saved automatically for future uses).
Generate a Custom Resume:

Open any job posting web page (e.g. LinkedIn, Indeed, Glassdoor, company career site).
Click the CV Customizer extension icon.
Click Create Custom CV.
The extension reads the job posting, generates a tailored summary, inserts it into your .docx template, and gives you a link to download your customized resume!
